# AGENTS.md

## Layout

- Official website of Thanal MEC. The only app is a Sanity Studio (Sanity v6, React 19, TypeScript) under `thanal-website/`; no public-facing site or frontend code exists yet.
- Run all npm/Sanity commands from `thanal-website/` — the repo root has no `package.json`.
- `sanity.config.ts` wires the Studio (project ID `jnfoaz0g`, dataset `thanal`, `structureTool()` + `visionTool()`); `sanity.cli.ts` repeats the project ID/dataset for the CLI. Keep both in sync.
- Schemas live in `schemaTypes/` and must be added to the `schemaTypes` array in `schemaTypes/index.ts` (currently empty).
- No test runner, lint/typecheck npm scripts, or CI. Studio deploys are manual; pushing does not deploy.

## Commands (run in `thanal-website/`)

- Install: `npm install` (npm; `package-lock.json` present)
- Dev: `npm run dev`
- Build: `npm run build`
- Typecheck: `npx tsc --noEmit`
- Lint: `npx eslint .`
- Format: Prettier config is inline in `package.json` (`semi: false`, `singleQuote: true`, `bracketSpacing: false`, `printWidth: 100`); use `npx prettier --check <files>` / `--write`, not on generated `.sanity/`.
- Deploy: `npm run deploy`; `npm run deploy-graphql` for the GraphQL schema.

## Gotchas

- `.sanity/` is generated by `sanity dev`, and `node_modules/` is installed; both are gitignored — never edit or commit them.
- `.gitignore` is inside `thanal-website/`; there is no root-level `.gitignore`.
- Default branch is `main`; remote is `github.com/thanal-mec/website`; root is MIT-licensed.
